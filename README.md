# Margalla Riders

A meeting point for motorbike riders in Islamabad and Rawalpindi.

- **Riders:** profiles with bike, riding level and free dates, with date matching
- **Routes:** club routes from Pir Sohawa to Khunjerab Pass, with difficulty, elevation profile, road surface, stages and rider highlights
- **Availability:** a calendar of who is free to ride each day
- **Group rides:** plan a ride on a route and let others join

This GitHub Pages site is the public preview with sample riders. Distances and altitudes are approximate. Check road and border status before riding.

Live site: https://shobiii942-coder.github.io/margalla-riders/
